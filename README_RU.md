# Yandex Disk Sync for Obsidian

Плагин для синхронизации заметок Obsidian с Яндекс Диском. Позволяет автоматически синхронизировать vault между несколькими устройствами через облачное хранилище Яндекса.

## Возможности

- **Реал-тайм синхронизация** — автоматическая загрузка изменённых файлов при сохранении
- **Периодическая полная синхронизация** — проверка и синхронизация всех файлов по таймеру
- **Двусторонняя синхронизация** — изменения с любого устройства синхронизируются на все остальные
- **Разрешение конфликтов** — автоматическое разрешение конфликтов (более новый файл побеждает)
- **Синхронизация удалений** — удалённые файлы удаляются на всех устройствах
- **Гибкие фильтры** — настраиваемые паттерны включения/исключения файлов
- **Поддержка нескольких устройств** — работа под одним токеном на разных устройствах

## Установка

### Вручную

1. Скачайте `main.js`, `manifest.json` и `styles.css` из [последнего релиза](../../releases)
2. Создайте папку `yandex-disk-sync` в `<Vault>/.obsidian/plugins/`
3. Скопируйте скачанные файлы в созданную папку
4. Перезапустите Obsidian
5. Включите плагин в **Settings → Community plugins**

### Через BRAT (для бета-тестирования)

1. Установите плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat)
2. Добавьте репозиторий через BRAT

## Настройка

### Получение OAuth токена

1. Перейдите на [Яндекс OAuth](https://oauth.yandex.ru/)
2. Создайте приложение с правами `cloud_api:disk.app_folder` или `cloud_api:disk.read` + `cloud_api:disk.write`
3. Получите OAuth токен
4. Вставьте токен в настройках плагина

### Настройки плагина

| Параметр                     | Описание                                                          |
| ---------------------------- | ----------------------------------------------------------------- |
| **OAuth token**              | Токен для доступа к Yandex Disk API                               |
| **Remote path**              | Путь к папке на Яндекс Диске (например, `obsidian-sync/my-vault`) |
| **Real-time sync**           | Автоматическая синхронизация при изменении файлов                 |
| **Full sync interval**       | Интервал полной синхронизации в минутах (0 = только вручную)      |
| **Sync delay**               | Задержка перед загрузкой файла после изменения (debounce)         |
| **Sync config folder**       | Синхронизировать папку настроек Obsidian                          |
| **Include/Exclude patterns** | Glob-паттерны для фильтрации файлов                               |

## Команды

| Команда              | Описание                                             |
| -------------------- | ---------------------------------------------------- |
| `Sync now`           | Запустить полную синхронизацию вручную               |
| `Pause/Resume sync`  | Приостановить или возобновить синхронизацию          |
| `Show sync status`   | Показать статус и статистику последней синхронизации |
| `Force upload all`   | Принудительно загрузить все локальные файлы          |
| `Force download all` | Принудительно скачать все файлы с диска              |

## Использование

### Первый запуск

При первом запуске плагин проверит наличие файлов локально и на Яндекс Диске:

- **Если локальный vault пуст, а на диске есть файлы** — файлы будут скачаны
- **Если на диске пусто, а локально есть файлы** — файлы будут загружены
- **Если файлы есть в обоих местах** — будет предложен выбор стратегии синхронизации

### Работа на нескольких устройствах

1. Настройте плагин на первом устройстве и выполните первичную синхронизацию
2. На втором устройстве установите плагин с тем же токеном и путём
3. Плагин автоматически скачает файлы с Яндекс Диска

### Разрешение конфликтов

При конфликте (файл изменён на нескольких устройствах) плагин автоматически выбирает более новую версию по времени модификации.

## Разработка

### Требования

- Node.js 18+
- npm

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

### Сборка

```bash
npm run build
```

Собранные файлы будут в папке `build/` и автоматически скопированы в тестовый vault.

### Линтинг

```bash
npm run lint
```

## Безопасность

- OAuth токен хранится локально в настройках плагина
- Токен не логируется и не передаётся третьим сторонам
- Рекомендуется использовать токен с минимально необходимыми правами

## Ограничения

- Максимальный размер файла для загрузки: 50 MB (ограничение Yandex Disk API)
- Синхронизация бинарных файлов может быть медленнее
- Не поддерживается синхронизация симлинков
