Каталог сценариев задаёт ожидаемое поведение; архитектура и тематические
документы объясняют реализацию. Исторический отчёт не вводит новые требования.
При изменении алгоритма обновляйте затронутые сценарии и документ владельца,
сохраняя стабильные ID и точные ссылки на проверки.

`auto:` и `manual:` обозначают способ проверки, а не результат прогона.
Результаты реального release-прогона хранятся в
[release-evidence/2.0.0.json](release-evidence/2.0.0.json); фактический статус
проверяйте там. Автоматические checks не подтверждают ручные сценарии.

Правила работы с кодом и тестами: [AGENTS.md](../AGENTS.md).
